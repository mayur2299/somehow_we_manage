# CREATE 2026 — Submission Guidelines (from create.radix360.site)

All teams deploy their final project using Netlify.

## Deadline
11 Sept — submissions close 23:59 IST / 22:29 GST. Hard stop.

## 1. Netlify access
Organisers create a dedicated Netlify project per team ahead of time. Do not create your own.
The Main Builder is added as a Developer collaborator (enough to link a repo, deploy, rename the site).
1. Accept the Netlify invite for the team's project (email invite; sign in with Radix email).
2. Link the team's code repository to it.
3. Make sure the final version is live and working before the deadline.
4. Submit the final Netlify URL through the Project Submission panel in My Team.

## 2. Deploying
The project is already in the Netlify dashboard after accepting the invite. Use it, do not create a new site.
1. Open the project and link the team repo.
2. Let it deploy. Netlify generates a URL, e.g. last-level-maniacs.netlify.app
3. Rename the default URL to the team or project name, e.g. team-codebreakers.netlify.app

## 3. Make sure it's public
Judges must open the URL without signing in to Netlify or requesting access. Check in Incognito / Private:
1. The page loads correctly
2. No login or Netlify authentication is required
3. All pages and features needed for the demo work
4. The version visible is the final submission
Developer access to build is separate from visitor access to view.

## 4. Submit the final URL
Submit through the Project Submission panel in My Team. This is the version used for judging and the pitch.

Before you submit:
- Final build is live
- URL opens in Incognito
- No login required
- Correct Netlify URL
- External services are working

After submitting, do not rename the Netlify site or change the submitted URL.

## 5. At the deadline
Organisers will:
1. Change the team's Netlify access from Developer to Reviewer
2. Lock auto-publishing so a later push cannot overwrite the submission
The version live at the deadline stays as submitted.

## 6. External services and backends
Anything outside Netlify (Firebase, Supabase, Render, AWS, external APIs, separately hosted DB/backend)
must also stay unchanged after the deadline. Judges should see exactly what was submitted.
